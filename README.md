# 📈 Algorithmic Trading Simulator (Paper Trading System)

A **distributed algorithmic trading simulator** built using **Java, Spring Boot, Microservices, gRPC, and WebFlux**.

This project simulates a real-world **algorithmic trading workflow** — including market price generation, strategy evaluation, trade execution, and portfolio tracking — **without using real money**.

The primary goal of this project is to demonstrate **backend system design, microservice communication, and clean architecture**, rather than complex financial modeling.

---

## 🚀 Key Features

- 📊 Simulated real-time stock prices
- 🧠 Pluggable trading strategy engine (mean reversion)
- ⚙️ Automated BUY / SELL trade execution
- 💼 Portfolio management with holdings and P&L
- 🔁 Simulation lifecycle management
- 🌐 REST APIs for portfolio dashboard
- 🔌 gRPC for low-latency inter-service communication
- 🧭 Service discovery using Netflix Eureka
